# 05. MVP 전략

## 🎯 MVP 철학

> **"완벽한 기술보다 완벽한 경험"**

### 핵심 원칙
**사용자 관점**: "와, 정말 자동으로 되네!"
**우리 관점**: "수작업이라도 그 경험을 만들어주자"

**Wizard of Oz 접근법**: 사용자는 마법을 경험하고, 우리는 뒤에서 마법사 역할

---

## 🚀 MVP 목표

### 검증하고 싶은 가설
1. **사용자들이 정말로 "재고 관리 제로" 경험을 원하는가?**
2. **이 경험에 대해 돈을 지불할 의향이 있는가?**
3. **우리의 핵심 가치 제안이 실제로 작동하는가?**

### 성공 기준
- **정량적**: 재고 관리 시간 50% 단축, 폐기율 30% 감소
- **정성적**: "정말 편해졌다", "자동으로 되는 것 같다" 피드백
- **비즈니스**: 고객이 유료 전환 의향 보임

---

## 🎪 MVP 사용자 경험 시나리오

### Phase 1: 온보딩 (1-2일)
```
📞 우리 → 원장: "이제 재고는 신경 쓰지 마세요"
📱 앱 설치: 직원용 간단한 재고 입력 앱
👥 교육: "하루 한 번만 사용량 체크해주세요" (15분)
🎯 약속: "한 달 후부터는 정말 아무것도 안 하셔도 됩니다"
```

### Phase 2: 데이터 수집 (2-4주)
```
📱 직원 일과:
   오전 10시: 앱 알림 "어제 사용량 입력해주세요"
   📝 입력: 비타민C 세럼 3개, 보톡스 2개... (5분)
   ✅ 완료: "감사합니다! 분석 중..."

🖥️ 우리 일과:
   📊 데이터 분석: 엑셀로 소비 패턴 계산
   📈 예측 모델링: 언제 떨어질지 수작업 계산
   📋 발주 계획: 최적 수량 수동 산출
```

### Phase 3: 첫 자동 발주 (3-4주차)
```
📲 원장 카톡: "비타민C 세럼 자동 발주 제안 (20개)"
📲 상세 정보: "현재 7개 → 3일 후 부족 예상"
📲 근거: "지난 3주 평균 사용량 기반 계산"
🖱️ 원장: "승인" (1클릭)
📲 확인: "주문 완료! 내일 오후 배송 예정"

🏃‍♂️ 우리가 실제로 하는 일:
   📞 공급업체에 직접 전화 주문
   📦 배송 일정 확인 후 원장에게 알림
   💰 결제 처리 및 영수증 발송
```

### Phase 4: 완전 자동화 체험 (1개월 후)
```
📱 직원: "요즘 재고 체크 안 해도 되네요?"
📲 원장: "승인만 누르면 알아서 주문되네"
📊 월말 리포트: "폐기 손실 80% 감소, 관리 시간 90% 단축"
💬 원장: "이거 다른 원장들한테 소개해줘야겠다"
```

## 🛠️ MVP 기술 아키텍처

### Frontend (고객 접점)
**직원용 앱 (초간단)**
```
📱 메인 화면:
   - 오늘의 사용량 입력
   - 현재 재고 현황 (우리가 계산해서 업데이트)
   - 발주 예정 알림

📱 기능:
   - 제품별 사용량 입력 (숫자만)
   - 푸시 알림 (입력 리마인더)
```

**원장용 인터페이스**
```
📲 카카오톡 채널:
   - 발주 제안 메시지
   - 승인/거부 버튼
   - 주문 완료 알림
   - 월간 리포트
```

### Backend (우리 작업 도구)
**운영 대시보드**
```
🖥️ 관리자 패널:
   - 고객별 재고 현황
   - 발주 제안 생성 도구
   - 주문 처리 상태 관리
   - 카톡 메시지 발송 도구
```

**데이터 처리**
```
📊 분석 도구:
   - 엑셀 기반 소비 패턴 분석
   - 발주량 계산기
   - 폐기 위험 체크리스트
```

## 👥 MVP 운영 체계

### 팀 구성 (최소 인력)
**Customer Success Manager (1명)**
- 고객 온보딩 및 관계 관리
- 피드백 수집 및 개선사항 도출

**Data Analyst (1명)**
- 재고 데이터 분석 및 발주량 계산
- 소비 패턴 분석 및 예측

**Operations Manager (1명)**
- 주문 처리 및 공급업체 관리
- 카톡 메시지 발송 및 고객 응대

**Developer (1명)**
- 간단한 앱 개발 및 유지보수
- 자동화 도구 개발

### 운영 프로세스
```
📅 Daily (평일):
   09:00 - 고객 데이터 수집 확인
   10:00 - 발주 필요 항목 분석
   11:00 - 발주 제안 메시지 준비
   14:00 - 승인된 주문 처리
   16:00 - 배송 상태 업데이트

📅 Weekly:
   - 소비 패턴 분석 업데이트
   - 고객 만족도 체크
   - 개선사항 회의

📅 Monthly:
   - 성과 리포트 생성
   - 고객별 ROI 계산
   - 다음 달 운영 계획 수립
```

## 💰 MVP 비용 구조

### 초기 투자
**개발비**: 500만원 (간단한 앱 + 관리 도구)
**운영비 (월)**: 800만원 (인건비 4명)
**마케팅비**: 200만원 (초기 고객 확보)

### 수익 모델 (MVP 단계)
**월 구독료**: 50만원/지점
**목표 고객**: 10개 지점 (월 500만원 수익)
**손익분기**: 6개월차 (고객 확보 시)

### 확장성 검증
- **고객당 운영비용**: 20만원/월 (목표: 10만원 이하)
- **자동화 가능성**: 70% (AI/시스템으로 대체 가능)
- **시장 규모**: 전국 피부과 1000개 이상

## 📊 MVP 검증 지표

### 사용성 지표
- **앱 사용률**: 90% 이상 (일일 입력)
- **입력 완료율**: 95% 이상
- **사용자 이탈률**: 10% 이하

### 가치 지표
- **재고 관리 시간 단축**: 50% 이상
- **폐기율 감소**: 30% 이상
- **발주 정확도**: 90% 이상

### 비즈니스 지표
- **고객 만족도**: NPS 50 이상
- **재계약률**: 80% 이상
- **추천 의향**: 70% 이상
- **유료 전환율**: 60% 이상

### 학습 지표
- **소비 패턴 예측 정확도**: 80% 이상
- **운영 효율성**: 고객당 처리 시간 단축
- **자동화 로드맵**: 단계별 개선 계획 수립

---

## 🚧 MVP 위험 요소 및 대응책

### 주요 위험
1. **고객이 수작업 티를 눈치챌 수 있음**
   - 대응: 빠른 응답과 정확한 서비스로 커버

2. **운영비가 수익을 초과할 수 있음**
   - 대응: 단계적 자동화로 비용 절감

3. **고객 확보가 어려울 수 있음**
   - 대응: 무료 체험 기간 연장, 추천 인센티브

### 피봇 계획
- **6개월 내 고객 10개 미확보 시**: 타겟 변경 또는 가격 조정
- **운영비 절감 불가 시**: 기능 단순화 또는 자동화 가속
- **고객 만족도 저조 시**: 서비스 모델 재검토

---

## 🎯 MVP 이후 로드맵

### 6개월 목표
- **검증 완료**: 제품-시장 적합성 확인
- **자동화 30%**: 반복 업무의 시스템화
- **고객 20개**: 안정적 수익 기반 구축

### 1년 목표
- **완전 자동화**: AI 기반 예측 시스템 구축
- **확장 준비**: 타 업종(치과, 한의원) 진출 검토
- **시리즈 A**: 본격적 성장을 위한 투자 유치
