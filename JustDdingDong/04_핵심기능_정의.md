## 🔥 핵심기능 1: 실시간 재고 자동 추적

### 해결하는 핵심 문제
**"엑셀과 현실의 괴리로 인한 잘못된 의사결정"**

#### Before (현재 상황)
```
실무진: "엑셀에는 10개라고 되어있는데..."
실무진: "실제로 세어보니 7개네요"
원장: "그럼 정확히 몇 개야?"
실무진: "음... 다시 세어볼게요"
```

#### After (우리 서비스)
```
시스템: "비타민C 세럼 현재 7개 (실시간)"
시스템: "예상 소진일: 3일 후"
```

### 기능 상세
- **실시간 사용량 자동 기록**
- **정확한 현재 재고 현황 파악**
- **유효기간 기반 우선순위 관리**
- **지점별 통합 현황 대시보드**

### 해결되는 Pain Points
✅ 실무진: "엑셀과 현실의 괴리" 완전 해결
✅ 실무진: "애매한 판단 상황" 제거
✅ 원장: "지점별 재고 현황 파악 어려움" 해결
✅ 원장: "불투명한 지출 현황" 투명화

## 🔥 핵심기능 2: AI 기반 자동 발주 제안

### 해결하는 핵심 문제
**"언제, 얼마나 주문할지 매번 고민하는 의사결정 피로"**

#### Before (현재 상황)
```
실무진: "원장님, 보톡스 떨어져가요"
원장: "얼마나 주문할까?"
실무진: "음... 지난번에 30개 주문했는데..."
원장: "그럼 50개로 주문해"
(2개월 후)
실무진: "원장님, 보톡스 10개가 유효기간 지났어요..."
```

#### After (우리 서비스)
```
카카오톡: "보톡스 자동 발주 제안 (25개)"
카카오톡: "예상 소진: 6주, 폐기 위험: 0%"
원장: "승인" (클릭 한 번)
✨ 끝 ✨
```

### 기능 상세
- **소비 패턴 AI 학습 및 분석**
- **최적 발주 시점 자동 계산**
- **적정 발주량 제안 (폐기 위험 최소화)**
- **카카오톡 간편 승인 시스템**
- **자동 발주 진행 및 배송 추적**

### 해결되는 Pain Points
✅ 원장: "매월 200만원 반복 폐기 손실" → 90% 절감
✅ 원장: "하루 종일 재고 관련 업무 방해" → 완전 해방
✅ 실무진: "매일 반복되는 비효율적 체크 업무" → 자동화
✅ 실무진: "원장님께 질문하는 부담" → 제거

## 💎 핵심 가치 실현

### 이 2가지 기능으로 달성되는 것

#### "Zero Touch 재고 관리" 완성
1. **걱정 제로**: 재고 부족을 걱정할 필요 없음
2. **업무 제로**: 재고 체크, 발주 업무에서 완전 해방
3. **실수 제로**: 인적 오류로 인한 품절/과다재고 없음
4. **낭비 제로**: 유효기간 만료로 인한 폐기 최소화

#### ROI 명확화
- **비용 절감**: 월 평균 폐기 비용 90% 절감
- **시간 절약**: 재고 관리 업무 시간 80% 단축
- **리스크 제거**: 품절로 인한 진료 차질 방지
- **확장성**: 지점 증가 시에도 관리 부담 증가 없음
